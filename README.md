# AI-investment-dashboard

## 项目简介

一个长期迭代的个人 AI 投资研究控制台，目标是快速上线具有 Apple 风格 UI 的投资 Dashboard。

## 当前状态

当前处于 **STEP 0：项目初始化**。已建立产品文档、开发路线、技术方案和基础目录；尚未开发具体功能或安装项目依赖。

## 开发阶段

- STEP 0：项目初始化（当前）
- STEP 1：MVP UI 开发（假数据）
- STEP 2：网站部署上线
- STEP 3：接入真实股票行情 API
- STEP 4：接入 OpenAI API
- STEP 5：用户系统和数据库
- STEP 6：个人 AI 投资助手

## 开发原则

- 以快速交付可用 MVP 为优先，按阶段逐步迭代。
- 保持实现简单，只在当前阶段确有需要时增加依赖和架构复杂度。
- STEP 1 使用假数据完成 UI；真实行情、AI API、用户系统和数据库按路线图分阶段接入。
- 每个阶段完成后更新项目状态和后续计划。

## 后续计划

下一步进入 STEP 1，基于假数据实现 Dashboard 首页、关注列表、股票详情、模拟 AI 对话、投资组合和每日 AI 市场简报。详见 [开发路线](docs/ROADMAP.md)、[产品说明](docs/PRODUCT.md) 和 [技术方案](docs/TECH_STACK.md)。
