# 开发路线

## STEP 0：项目初始化

完成项目规划、基础目录结构和开发规范建立。

## STEP 1：MVP UI 开发（假数据）

实现具有 Apple 风格的投资 Dashboard 界面，使用假数据展示核心页面和交互。

## STEP 2：网站部署上线

将 MVP 部署到 Vercel 并完成基础线上验证。

## STEP 3：接入真实股票行情 API

评估并接入 Polygon 或 Alpha Vantage 等行情数据服务。

## STEP 4：接入 OpenAI API

为 AI 对话和市场简报接入 OpenAI API。

## STEP 5：用户系统和数据库

引入用户身份认证与数据库，优先评估 Supabase。

## STEP 6：个人 AI 投资助手

在行情、用户数据和 AI 能力基础上迭代个人化投资研究体验。
